# 滑动变阻器 · DeepSeek Harness 皮肤

把滑动变阻器嵌进 DeepSeek Harness Web 界面：

- 滑杆出现在输入框工具行里、「工作区内修改」右侧、模型选择器左侧。
- 照片从主界面正中间偏右开始覆盖显示，左侧柔和淡出，叠在对话区后面。
- 整页背景从 frame-00 的冷灰影棚底，逐渐过渡到 frame-30 的深黑底，并以照片为圆心扩散帝王金光。
- 选择 DeepSeek 大模型时，滑杆绑定该模型的推理等级，模型名称后面的档位后缀会跟着变。六个刻度对应：第 0 档 `off`，大于 0 到第 2 档 `low`，大于 2 到第 4 档 `high`，大于 4 到第 5 档 `max`。不是 DeepSeek 大模型时，拖动仍只改外观。
- 绑定生效时，官方模型菜单里的「推理等级」选项会隐藏，只通过滑动变阻器调节；模型名称后的档位后缀仍会显示。
- 悬停或拖动滑杆时，滑块上方出现小悬浮弹窗，六个区域依次显示小难梁、牢梁、梁子、梁圣、梁神、梁祖；绑着推理等级时会带上类似「梁神 · Max」的后缀。
- 滑到最后一格（梁祖）时，左上角 logo 去掉黑底，只保留图标和文字；对话框仍为深色。
- 从第五格起，Windows 标题栏左上角的「应用」「编辑」改为浅色文字。
- 空会话标题旁的「预览版」徽章改为黑底金字。
- 从第五格起，「默认工作区」和「标准模式」触发文字改为金色；打开后菜单为黑底，模式菜单标题金色、说明浅色，工作区菜单文字为金色。
- 从第五格起，右上角分页图标和打开后顶栏图标改为浅色；开始页四个工具按钮为黑底、标题金色、说明和快捷键白色；指南针金色；「更多工具」菜单为黑底金字。
- 从第五格起，上方会话标题和 AI 思考文字改为浅色，避免压在深色背景上看不清。
- 从第五格起，正常 AI 回答为白色；用户气泡和思考内容里白底标签的文字为黑色，超链接为蓝色，「处理失败」「本轮运行失败」等失败提示为红色。
- 从第五格起，窗口右上角最小化、最大化、关闭三个系统按钮改为浅色。
- 从第五格起，插件页和自动化任务页的正文改为白色。
- 从第五格起，打开轨迹后底板改为黑色、文字改为白色，每行的彩色表头（助手、工具、上下文等）保持原样。
- 档位保存在当前浏览器的 `localStorage`。

## 安装

需要先安装 DeepSeek Harness，并且终端里能运行 `dsh`。

在插件目录下执行（路径按你实际放置的位置修改）：

```sh
dsh plugin --profile web add "F:\huadong\dsh-liang-rheostat-skin"
```

然后重启 Web 界面：

```sh
dsh web
```

若你用的是官方 Desktop，请把 `--profile web` 改成你的桌面 profile 名（常见为 `desktop`），安装后完全退出并重新打开应用。

装完后打开一个会话，输入框「工作区内修改」右侧应出现迷你滑动变阻器和称号（小难梁…梁祖），主界面右侧出现人物照片。

## 卸载

```sh
dsh plugin --profile web remove dsh-liang-rheostat-skin
```

然后重启 `dsh web`。

## 开发

```sh
npm install
npm run build
```

`lib/client.js` 需要提交/分发；改 `src/client/index.jsx` 后必须重新构建。
